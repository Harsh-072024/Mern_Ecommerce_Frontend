# 🛒 MERN Stack E-Commerce Web Application (Frontend)

A full-featured **MERN Stack E-Commerce frontend application** built using **React 18, Redux Toolkit, and Tailwind CSS**.  
The platform supports **user authentication, product browsing, cart & checkout, online payments, admin management**, and **email notifications**.

This project is built as a **real-world portfolio project** to demonstrate full-stack development skills.

---

##  Features

### User Features
- User registration & login
- Product listing & product details page
- Sorting, Filtering, and Pagination queries using Mongoose
- Add to cart & update quantity
- Secure checkout flow
- Online payments (Stripe) & Cash on Delivery
- View order history
- User profile management
- Order confirmation & password reset emails

### Admin Features
- Admin dashboard
- Add / edit / delete products
- Manage orders
- Update order status
- User management

---

## Tech Stack

### Frontend
- **React 18**
- **Redux Toolkit** (Async Thunks)
- **React Router v6**
- **Tailwind CSS**
- Axios

### Backend (Separate Repository)
- Node.js
- Express.js
- MongoDB (Mongoose v7)
- Passport.js (Local & JWT)
- Nodemailer (Email service)
- Razorpay (PaymentIntent based flow)

---

## Architecture
- REST API based client-server architecture
- JWT authentication
- Role-based access control (Admin / User)
- MongoDB Atlas cloud database
- Deployed using **Vercel**
